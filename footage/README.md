# Footage

Official GTA VI trailers and your own gameplay clips go here, as .mp4.

- Name them clearly: `trailer1.mp4`, `trailer2.mp4`, `launch-trailer.mp4`, `gameplay-2026-11-19-chase.mp4`.
- Keep each file under 90 MB (GitHub refuses files over 100 MB). 1080p H.264 is plenty.
- Only official Rockstar material or footage you recorded yourself. No leaks.

The automatic runs use `scenes.py` to find shots and `make_clip.py` to cut vertical Reels from them.
